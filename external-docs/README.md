# NMR Lab Notebook Help

These files are user-facing documentation. They are written so the React app can later render them as in-app help without rewriting the content.

## Guides

- `getting-started.md`: run the local app and backend.
- `projects.md`: understand project organization.
- `workflow-library.md`: use shared workflow templates.
- `running-experiments.md`: instantiate and track experiments.
- `attaching-photos.md`: attach gels, photos, and screenshots.
- `calculator.md`: use the molarity-style calculator.
- `teams-and-chat.md`: use lab channels and persisted discussion threads.
- `ai-and-mcp.md`: understand the current AI placeholders and future MCP direction.
- `roles.md`: understand lab roles and permissions.
- `troubleshooting.md`: common local development and user workflow issues.
- `glossary.md`: core terminology.
