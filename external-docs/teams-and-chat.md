# Teams And Chat

Use the Teams page to keep lab discussion tied to real workflow and experiment context.

## What You Can Do

- create a local channel
- post a message
- reference a workflow
- reference an experiment
- attach an image such as a gel or chromatography screenshot

## Suggested Use

- `general` for broad lab updates
- `anc2-purification` for ANC2-specific troubleshooting
- new channels for SEC review, NMR prep, or a specific active experiment

## Persistence

Messages are stored in the local SQLite database. If you refresh the page, the channel list and message history should still be there.

## Current Limits

- local mode only
- no live multi-user push yet
- image attachments only
