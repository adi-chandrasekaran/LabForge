# Glossary

## Project

The top-level scientific effort, such as ANC2 purification.

## Workflow

A reusable procedure template made of ordered steps and optional branch tracks.

## Workflow Step

One procedural unit inside a workflow. A step can include inputs, outputs, parameters, notes, procedure text, and attachments.

## Experiment

A real dated run of one or more workflow templates.

## Experiment Step Run

A snapshot of a workflow step inside a real experiment. It stores progress and observations independently from the template.

## Attachment

A file linked to a workflow step or experiment step run, such as a gel image or screenshot.
