# Running Experiments

An experiment is a dated run of one or more workflows. It is separate from the workflow template so real observations do not overwrite the shared procedure.

## Current Flow

1. Open the `Workflow` page.
2. Click `Start ANC2 Experiment`.
3. The app creates a new dated experiment from `ANC2 Batch 1` and `ANC2 Batch 2`.
4. Use the experiment run panel to edit a live step such as `Dialysis`.
5. Save the step and refresh the page to confirm the run state persisted.

## What Persists

- Experiment title and date
- Batch 1 and Batch 2 workflow runs
- Step status
- Procedure edits made to the run
- Notes entered during the run

## What Does Not Change

Editing an experiment step does not modify the ANC2 workflow library template. This is intentional so the shared protocol stays reusable.
