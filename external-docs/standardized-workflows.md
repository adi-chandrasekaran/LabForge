# Standardized Workflows

Standardized workflows are published, reusable lab procedures.

## What They Are

- Shared workflow templates for stable procedures
- Readable by the wider lab
- Editable only by workflow owners and editors

Examples currently seeded in the app:

- Reverse Nickel Chromatography
- Ion Exchange Chromatography

## What You Can Do

- Open the `Standardized Workflows` page
- Create a new standardized workflow with title, description, tags, and optional members
- Inspect the procedure step-by-step
- Review owners, editors, and other workflow members
- If you are an owner or editor, add, edit, and delete workflow steps
- If you are an owner or editor, add and delete diverging branches
- Delete a standardized workflow after confirming the destructive action
- Reuse the workflow from experimental workflow add-step or branch flows

## Permissions

- `owner`: full control
- `editor`: can update steps, branches, details, and publish
- `commenter`: read-only for now
- `viewer`: read-only

## Reuse Behavior

When you insert a standardized workflow into an experimental workflow, the app copies the standardized steps into that project workflow. The copied steps become editable for that project workflow and do not change the original standardized workflow.

## Creating A Dummy Standardized Workflow

1. Open `Standardized`.
2. Click `+ New Standardized Workflow`.
3. Enter a title, description, and comma-separated tags.
4. Save the workflow.
5. Use `+ Add Step` to build the schematic.
6. Use edit/delete controls on the steps as needed.
7. Use `Delete` to remove the dummy workflow when finished testing.
